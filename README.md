# Lemon Korean releases

Signed Android APKs of the Lemon Korean app and the version manifest the app checks.
The app's source code is private; this repository holds release files only.

- Each release (`vX.Y.Z`) carries the APK and `version.json`.
- The app reads `https://github.com/chelly1221/lemonkorean-releases/releases/latest/download/version.json`
  and asks for an update when a newer build exists. Updating is required to keep using the app.
- The web app and the iPhone home-screen app at https://lemon.3chan.kr/app/ update themselves.

# 레몬 한국어 릴리스

레몬 한국어 앱의 서명된 Android APK와, 앱이 확인하는 버전 정보(`version.json`)를 올리는 곳입니다.
소스 코드는 비공개이고 이 저장소에는 릴리스 파일만 있습니다.
